PrepAI — AI Mock Interview Platform

A full-stack application designed to help users practice interviews, 
receive AI-generated feedback, and track their interview preparation.

Features

- AI-powered mock interview practice
- User authentication and account management
- Interview sessions and feedback
- Organized backend with routes, controllers, services, and validations
- Responsive React user interface

 Tech Stack

- Frontend: React, JavaScript, CSS
- Backend: Node.js, Express.js
- AI Integration: Google Gemini API
- Database: Configure according to the project's actual database setup

 Getting Started

Prerequisites: Node.js, npm, and the configured database.

1. Clone the repository:

   git clone https://github.com/janavi06/ai-interview-site.git
   cd ai-interview-site
  

2. Install dependencies in both backend/ and frontend/.

3. Configure the required environment variables, including the AI API key and database connection.

4. Start the backend and frontend using the npm scripts defined in their respective package.json files.
